# Survey Data Investigation

## 📌 Project Overview

This project analyzes developer survey data using Python.

## 🎯 Objectives

- Analyze developer education and employment
- Study work experience and yearly salary
- Analyze remote work preferences
- Study job satisfaction
- Create data visualizations
- Perform basic statistical analysis

## 🛠️ Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📊 Analysis Performed

- Dataset inspection
- Data cleaning
- Exploratory Data Analysis (EDA)
- Age distribution
- Yearly salary distribution
- Remote work analysis
- Education vs salary analysis
- Work experience vs salary analysis
- 95% confidence interval

## 📁 Project Files

- `Survey_Data_Investigation.ipynb` — Complete analysis with code, outputs and graphs
- `Survey_Data_Investigation_Project_Report.docx` — Project documentation

## ✅ Conclusion

The project demonstrates how Python can be used to analyze survey data and identify useful patterns related to education, employment, experience, salary, remote work and job satisfaction.
